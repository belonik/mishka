# Mishka 🐻

Заметочник для macOS Sequoia в духе [Bear](https://bear.app/): Markdown с живой подсветкой,
вложенные теги, аккуратная типографика и три колонки. Написан на SwiftUI и AppKit,
без единой внешней зависимости.

Заметки — обычные `.md`-файлы. Ничего не запирается в базе данных, индекс восстановим
сканированием папки, а любой файл можно открыть и править прямо там, где он лежит.

```
┌───────────┬───────────────┬──────────────────────────────┐
│  теги     │  заметки      │  редактор / превью           │
│  и        │  с поиском    │  с живой разметкой           │
│  разделы  │  и сортировкой│  и таблицами                 │
└───────────┴───────────────┴──────────────────────────────┘
```

## Быстрый старт

```bash
./build.sh release run
```

Соберётся `dist/Mishka.app` и сразу откроется. Нужны macOS 15+ и Xcode 26 (Swift 6.2).
При первом запуске создаётся хранилище и приветственная заметка.

Проверки:

```bash
./Tests/run-tests.sh      # 58 проверок в трёх наборах
```

## Что умеет

**Живой Markdown.** Разметка отображается прямо во время набора: заголовки растут,
`**жирный**` и `*курсив*` применяются на месте, `#теги` подсвечиваются, блоки кода не
разбираются как разметка. Символы разметки прячутся, но показываются приглушённо, стоит
поставить курсор в абзац, — их всегда можно поправить.

**Настоящие чекбоксы.** `- [ ]` превращается в кликабельный флажок на левом поле; `Enter`
продолжает список, `Tab` меняет уровень вложенности.

**Таблицы.** Оформляются как таблицы и в редакторе (карточка со скруглёнными углами,
полужирная шапка, полосы по строкам), и в превью. Колонки подстраиваются под содержимое,
выравнивание задаётся `:---`, `:---:`, `---:`.

**Теги.** `#работа/проекты` строит дерево в сайдбаре, счётчики учитывают вложенность,
переименование обновляет все заметки.

**Файлы на месте.** Любой `.md` открывается по `⌘O`, перетаскиванием или из Finder и
редактируется **без копирования** — правки идут прямо в оригинал. Приложение помнит такие
файлы: раздел **Files**, история в **Open Recent**, запись переживает перезапуск. Удалить
такой файл из приложения нельзя — только убрать запись; сам файл остаётся нетронутым.

**Оформление.** 16 тем и 12 акцентов, шесть гарнитур, размер текста, межстрочный интервал,
ширина колонки, режим фокуса. Контраст проверен численно.

**Ещё.** Поиск по заголовку, тексту и тегам, экспорт в `.md` / `.html` / `.pdf`, корзина с
автоочисткой, строка состояния со счётчиком слов, YAML-шапка отдельной карточкой метаданных.

## Данные

```
~/Library/Application Support/Mishka/
├── notes/<uuid>.md      заметки — чистый Markdown
├── trash/<uuid>.md      корзина
└── library.json         метаданные: даты, закрепление, корзина, история файлов
```

Индекс можно удалить — он пересоберётся. Другое хранилище задаётся при запуске:

```bash
open dist/Mishka.app --args --vault ~/Documents/Notes
```

## Структура

```
Sources/Mishka/
├── App/         точка входа, меню, состояние, настройки
├── Models/      Note, TagNode
├── Storage/     NoteStore — файлы, индекс, внешние файлы
├── Theme/       палитры: 16 тем, 12 акцентов
├── Markdown/    MarkdownRenderer — Markdown → HTML со стилями темы
├── Editor/      живая подсветка и NSTextView с гуттером
├── Views/       интерфейс
└── Support/     утилиты и экспорт
Tests/           проверки
Tools/           иконка и оффскрин-рендер вёрстки
```

~8 600 строк Swift в 20 файлах.
