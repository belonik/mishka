# Руководство пользователя

Mishka — заметочник для macOS в духе [Bear](https://bear.app/): Markdown, живые теги,
аккуратная типографика и три колонки. Заметки хранятся обычными `.md`-файлами.

---

## 1. Установка и запуск

```bash
./build.sh release run
```

Соберётся `dist/Mishka.app` и сразу откроется. Приложение можно перетащить в «Программы» —
оно самодостаточное, зависимостей нет.

Требуется macOS 15 Sequoia или новее. При сборке нужен Xcode 26 (Swift 6.2).

**Первый запуск.** Создаётся хранилище и приветственная заметка с подсказками. Ничего
дополнительно настраивать не нужно.

---

## 2. Что вы видите

Три колонки:

| Колонка | Что внутри |
| --- | --- |
| **Слева** | Разделы (Все заметки, Закреплённые, Файлы, To-do, Сегодня, Без тегов, Заблокированные, Корзина) и дерево тегов |
| **В центре** | Поиск, сортировка и список заметок: заголовок, дата, первые строки, теги |
| **Справа** | Редактор, превью или то и другое — переключается в панели инструментов |

Границы колонок перетаскиваются мышью, ширина запоминается.

Внизу справа — строка состояния: имя привязанного файла, когда правилась заметка, сколько
в ней слов, символов и сколько времени займёт чтение.

## 3. Заметки

### Создание и правка

- `⌘N` — новая заметка. Курсор сразу в тексте, ничего подтверждать не нужно.
- `⌘⇧N` — новая заметка из содержимого буфера обмена.
- Сохранение автоматическое: примерно через секунду после того, как вы перестали печатать.
  Отдельной кнопки «Сохранить» нет и не нужно.

**Заголовок заметки — это её первая содержательная строка.** Отдельного поля для названия
нет: как в Bear, вы просто пишете `# Заголовок` первой строкой.

### Закрепление, дублирование, блокировка

Правый щелчок по заметке в списке:

- **Pin** — закреплённые заметки всегда наверху;
- **Duplicate** — копия заметки;
- **Lock** — защита от случайной правки: заметка открывается только для чтения, пока вы
  не снимете блокировку. Это не шифрование и не пароль;
- **Reveal in Finder** — показать файл на диске;
- **Move to Trash** — в корзину (`⌘⌫`).

### Корзина

Удалённые заметки лежат в корзине и не исчезают сразу. В настройках можно выбрать срок
автоочистки: 7, 30, 90 дней или «никогда». В разделе **Trash** есть кнопка **Empty**.

Заметки, открытые из внешних файлов, корзина **не удаляет** — они только убираются из
списка (см. раздел 6).

## 4. Markdown

Разметка отображается прямо во время набора — отдельного режима «предпросмотр исходника»
нет. Символы разметки прячутся, но стоит поставить курсор в абзац, как они снова видны
приглушённым серым, чтобы их можно было поправить.

| Что | Как пишется |
| --- | --- |
| Заголовки | `#` … `######` — размер уменьшается от H1 к H6 |
| Жирный | `**текст**` или `__текст__` |
| Курсив | `*текст*` или `_текст_` |
| Жирный курсив | `***текст***` |
| Зачёркнутый | `~~текст~~` |
| Выделение | `==текст==` |
| Код в строке | `` `код` `` |
| Блок кода | ```` ```swift ```` … ```` ``` ```` — моноширинный шрифт на подложке, содержимое не разбирается как разметка |
| Цитата | `> текст` |
| Маркированный список | `- `, `* ` или `+ ` |
| Нумерованный список | `1. ` или `1) ` |
| Список задач | `- [ ]` и `- [x]` |
| Ссылка | `[текст](https://…)` |
| Картинка | `![подпись](путь) ` |
| Горизонтальная линия | `---` |
| Таблица | см. ниже |

### Списки задач — настоящие флажки

Набранное `- [ ]` превращается в кликабельный квадратик на левом поле. Щелчок по нему
переключает состояние, выполненный пункт приглушается. Отмену можно вернуть через `⌘Z`.

### Работа со списками с клавиатуры

- `Enter` в конце пункта продолжает список, сохраняя отступ и тип.
- `Enter` на пустом пункте завершает список.
- `Tab` и `⇧Tab` меняют уровень вложенности.

### Ссылки

`⌘`-клик по ссылке открывает её в браузере. Голые адреса вроде `https://example.com`
подсвечиваются автоматически.

## 5. Таблицы

Таблицы GFM оформляются как настоящие таблицы — и в редакторе, и в превью.

```markdown
| Направление | План | Факт | Статус |
| --- | ---: | ---: | :---: |
| Интервью | 24 | 0 | 🔴 |
| Демо | 12 | 3 | 🟢 |
```

**В редакторе** таблица выглядит карточкой: скруглённые углы, полужирная шапка, строки через
одну с лёгкой полосой, тонкие разделители. Символы `|` приглушены, чтобы читался текст, а не
разметка. Строка `|---|---|` сворачивается в тонкую линию под шапкой — если поставить на неё
курсор, она развернётся обратно, и её можно отредактировать.

**В превью** — компактная карточка с тонированной шапкой и выравниванием по колонкам:

- `:---` — по левому краю,
- `:---:` — по центру,
- `---:` — по правому краю.

**Колонки подстраиваются под содержимое.** Узкая таблица не растягивается на всю ширину
страницы — карточка обнимает самый широкий ряд. Если таблица шире страницы, она
ограничивается по ширине и прокручивается по горизонтали.

---

## 6. Теги

Теги пишутся прямо в тексте: `#идеи`, `#работа/проекты`, `#книги`. Пробел после решётки
делает строку заголовком, а не тегом, поэтому `# Заголовок` тегом не считается. Теги внутри
блоков кода игнорируются, как и фрагменты адресов (`https://…/page#section`).

Вложенность выражается слэшем: `#работа/проекты` и `#работа/встречи` соберутся в дерево
`работа → проекты, встречи`. Счётчик у родителя учитывает вложенные теги, поэтому свёрнутый
узел всё равно показывает, сколько внутри заметок.

Правый щелчок по тегу в сайдбаре:

- **Rename Tag…** — переименовать; изменения применятся ко всем заметкам, включая вложенные;
- **Delete Tag** — убрать тег из всех заметок;
- **Copy Tag** — скопировать `#тег` в буфер.

Разделы слева дают быстрые срезы: **To-do** — заметки с невыполненными задачами,
**Сегодня** — правленные сегодня, **Без тегов**, **Заблокированные**, **Корзина**.

## 7. Файлы на месте (без копирования)

Приложение умеет работать с любым Markdown-файлом там, где он лежит, — не копируя его
в свою библиотеку. Это удобно для заметок в git-репозитории или в чужой папке.

### Как открыть

- `⌘O` — выбрать файл;
- перетащить файл в окно;
- из Finder: правый щелчок → «Открыть в программе» → Mishka (или `open -a Mishka file.md`).

### Что происходит

Файл не копируется: правки идут прямо в оригинал, сохранение автоматическое. Другие
редакторы, git и система контроля версий продолжают работать с этим же файлом. В строке
состояния внизу показано имя привязанного файла — щелчок по нему показывает файл в Finder.

Приложение при этом помнит файл: он появляется в разделе **Files**, участвует в поиске и
тегах, его можно закрепить. Запись о пути сохраняется и переживает перезапуск.
**File ▸ Open Recent** хранит последние 15 файлов.

### Чего приложение не сделает

- **Не удалит ваш файл.** Команда называется **Remove from Mishka** и убирает только запись
  из приложения. Корзина внешние файлы не трогает.
- **Не создаст копию без спроса.** Копия появляется только по команде
  `File ▸ Copy Markdown into Library…` (`⌘⇧I`), если вы действительно хотите перенести файл
  в библиотеку.

### Если файл пропал

Запись остаётся в истории и помечается значком. В редакторе появится баннер **File not
found** с путём и кнопками:

- **Find Again…** — указать новое расположение файла;
- **Remove** — убрать запись из приложения.

Если файл изменили в другом редакторе, при возвращении в Mishka изменения подхватятся
автоматически.

## 8. Поиск и сортировка

- `⌘F` — поиск по всем заметкам: по заголовку, тексту и тегам, без учёта регистра.
  Найденные совпадения в заголовке подсвечиваются.
- `⌥⌘F` — поиск внутри открытой заметки.
- `⌥⌘↑` / `⌥⌘↓` — предыдущая и следующая заметка.
- Кнопка со стрелками над списком — сортировка по дате изменения, дате создания или
  названию, по возрастанию или убыванию.

---

## 9. Превью

Переключатель в панели инструментов: **редактор** / **пополам** / **только превью**.
Горячие клавиши — `⌥⌘1`, `⌥⌘2`, `⌥⌘3`.

Превью использует тот же шрифт и цвета, что и редактор. При наборе текста обновляется
только содержимое, поэтому позиция прокрутки не сбрасывается — можно печатать и
одновременно читать. Ссылки открываются в системном браузере.

Метаданные в начале файла (блок между `---`) показываются отдельной карточкой:

```markdown
---
owner: Продукт
status: active
---
```

## 10. Оформление

`⌘,` открывает настройки.

**Appearance** — 16 тем (6 светлых, 10 тёмных, включая Solarized, Dracula, Nord, Rosé Pine)
и 12 акцентных цветов, независимых от темы. По умолчанию включено следование системной
тёмной/светлой теме; чтобы выбрать тему вручную, выключите **Follow system appearance**.

**Typography** — гарнитура (системная, округлая, с засечками, Charter, Avenir Next,
моноширинная), размер текста, межстрочный интервал и ширина колонки. Здесь же показан
образец.

**Editor** — режим фокуса (приглушает всё, кроме текущего абзаца), проверка орфографии,
строка состояния, режим по умолчанию и срок хранения корзины.

## 11. Экспорт

Из панели инструментов или из правого щелчка по заметке:

- **Markdown (.md)** — исходный текст;
- **Web Page (.html)** — готовая страница с оформлением текущей темы;
- **PDF (.pdf)** — документ для печати или отправки.

Там же — **Copy as Markdown** и **Copy as HTML**.

## 13. Где лежат данные

```
~/Library/Application Support/Mishka/
├── notes/<uuid>.md      ваши заметки
├── trash/<uuid>.md      корзина
└── library.json         метаданные: даты, закрепление, корзина, история файлов
```

**Ваши заметки — это ваши файлы.** Их можно открыть в любом редакторе, положить в git,
синхронизировать через iCloud Drive или Syncthing.

`library.json` можно удалить: при следующем запуске он пересоберётся сканированием папки.
Потеряются только закрепление, состояния корзины и история внешних файлов — сами заметки
останутся на месте.

Другое расположение хранилища задаётся при запуске:

```bash
open dist/Mishka.app --args --vault ~/Documents/Notes
# или
MISHKA_VAULT=~/Documents/Notes open dist/Mishka.app
```

## 14. Частые вопросы

**Заметка не сохранилась.** Сохранение отложено примерно на секунду. Если приложение
закрыть сразу после набора, запись всё равно выполнится — на выходе данные дописываются
принудительно. Проверить можно, открыв файл в Finder: правый щелчок по заметке →
Reveal in Finder.

**Открыл файл, а он не появился в списке.** Убедитесь, что вы в разделе **All Notes** или
**Files** и что строка поиска пуста. Открытый файл всегда оказывается в **All Notes**.

**Внешний файл помечен значком предупреждения.** Файл перемещён, удалён или лежит на
отключённом диске. Нажмите **Find Again…** в баннере, чтобы указать новое место.

**Изменил файл в другом редакторе, а Mishka показывает старое.** Переключитесь в другое
приложение и обратно — файлы перечитываются при активации. Можно также нажать кнопку
обновления внизу сайдбара.

**Настроил тему, а она не применяется.** Проверьте, выключен ли переключатель
**Follow system appearance** в настройках: пока он включён, тема выбирается по системе.

**Хочу несколько окон.** Приложение сознательно однооконное: иначе каждое открытие файла
из Finder создавало бы новое окно. Разные хранилища можно открыть, запустив вторую копию
с другим `--vault`.

**Куда делась заметка после `⌘⌫`?** В корзину. Раздел **Trash** слева, там её можно
восстановить или удалить окончательно.
